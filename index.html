4Try it yourself

Run the readable example, measure the tradeoffs, and inspect the recorded measurements. Commands run from the repository root.

# Activate the environment and install required packages
# Generate an answer with a compressed cache
python -m examples.lowram_demo

# Compare memory, throughput, latency and accuracy
python -m benchmarks.compare \
  --methods baseline fast lowram \
  --meta-weights /path/to/meta_mlps.pt \
  --contexts 65536 --batch-sizes 1 2 4 \
  --ratios 4 --samples 4 --repeats 2 --warmup 1 \
  --decode-tokens 48 \
  --output results/demo/comparison.json
